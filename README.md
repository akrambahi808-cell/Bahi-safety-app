# Bahi Safety App — GitHub Pages

Static HTML/CSS/JavaScript storefront for Bahi Safety.

- WooCommerce Store API source: `https://bahisafety.com/wp-json/wc/store/v1`
- Categories appear immediately under the Hero.
- Products load in pages of 20.
- Product gallery, search, cart, WhatsApp and back navigation included.
- No PHP/server-side code required.

## GitHub Pages
Upload the contents of this ZIP to a GitHub repository and enable Pages from the repository's Pages settings.

For a custom domain, configure it from Settings → Pages after the site is working.
